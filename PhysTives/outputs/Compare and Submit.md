## Final Reflection

The structured prompt produced the most useful version because it clearly
defined the target users, features, technology, safety limits, and
acceptance criteria.

The zero-shot prompt was useful as a starting point, but it left many
requirements unspecified. Few-shot prompting helped make the movement
activity content more consistent. Role assignment helped identify
accessibility and health-content concerns. Structured analysis helped
identify a technical issue and provided a way to test the correction.

After applying the selected correction, I tested the activity controls,
progress tracker, reset control, keyboard interaction, and mobile layout.
The final version was selected because it best satisfied the original
project requirements.

I learned that AI-generated code must be inspected and tested before it is
accepted. The developer is still responsible for checking the
functionality, accessibility, safety, and quality of the final website.
